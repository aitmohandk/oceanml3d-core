# MonaiDirectUNet) on the monai 1.6 / torch 2.8 combination it was first

# it into the shared env drags torch forward and previously broke CUDA for

# this project's torch 2.4.1 without moving it (measured 2026-09-14).
#
# Use this file only to reproduce the original 1.6/2.8 runs, in a SEPARATE env.
# The +cu126 local version isn't on PyPI -- install with:
#   pip install -r requirements-monai.txt --extra-index-url https://download.pytorch.org/whl/cu126
